
# Contributing to 「SUB」

Thank you for your interest in improving this project.

## How to Contribute

You can contribute by:

- Reporting reproducible bugs.
- Suggesting practical improvements.
- Improving documentation.
- Fixing workflow or configuration-processing issues.
- Improving testing, reliability, and compatibility.

## Before Opening an Issue

- Search existing issues to avoid duplicates.
- Use the appropriate issue template.
- Include relevant logs and reproduction steps.
- Remove access tokens, private keys, credentials, and other sensitive information.

## Pull Request Process

1. Fork the repository.
2. Create a branch for your change.
3. Keep changes focused and explain their purpose.
4. Test your changes where practical.
5. Update documentation when behavior changes.
6. Submit a pull request using the provided template.

## Code and Workflow Guidelines

- Preserve existing functionality unless a change is intentional.
- Avoid unnecessary dependencies.
- Do not commit generated files unless required by the project workflow.
- Do not introduce secrets or personal credentials.
- Keep automated configuration updates reliable and reproducible.

## Review

Pull requests may be reviewed, requested for changes, or declined by the maintainer.

By submitting a contribution, you agree that it may be distributed under the project's applicable license.
