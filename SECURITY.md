
# Security Policy

## Supported Versions

Security fixes are applied to the current maintained version of 「SUB」.

Older revisions may not receive security updates.

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately rather than opening a public issue.

If GitHub Private Vulnerability Reporting is enabled for this repository, use the repository's **Security** tab to submit a report.

If private reporting is unavailable, contact the repository maintainer privately through GitHub.

## Please Include

- A description of the vulnerability.
- The affected file or workflow, if known.
- Steps to reproduce the issue.
- Potential impact and any suggested mitigation.

## Important

- Do not publish credentials, tokens, private keys, or private configuration links.
- Do not include live proxy credentials in public issues or pull requests.
- Avoid destructive testing against systems you do not own or have permission to test.

The maintainer will review reports and determine appropriate remediation and disclosure.
