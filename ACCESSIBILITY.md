
# Accessibility

The 「SUB」 project aims to make its documentation and repository workflows accessible and easy to use.

## Current Practices

- Use descriptive headings and link text.
- Prefer readable Markdown and clearly structured documentation.
- Provide meaningful labels and descriptions in issue templates.
- Avoid relying on color alone to communicate important information.
- Keep instructions understandable and reproducible.

## Feedback

If you encounter an accessibility barrier in the documentation or repository interface, please open an issue or contact the maintainer through GitHub.

Suggestions for improving accessibility are welcome.
