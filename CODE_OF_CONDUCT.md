
# Code of Conduct

## Our Pledge

We are committed to providing a respectful, inclusive, and constructive environment for everyone participating in the 「SUB」 project.

## Expected Behavior

- Be respectful and considerate.
- Provide constructive feedback.
- Respect different viewpoints and experiences.
- Focus on the issue, not the individual.
- Share information responsibly and avoid exposing private data.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Discriminatory or abusive language.
- Publishing private information without permission.
- Deliberate disruption of project discussions.

## Enforcement

Project maintainers may edit, remove, or reject contributions that violate this Code of Conduct.

Serious or repeated violations may result in restrictions on participation.

## Reporting

Report misconduct privately to the project maintainer through GitHub. Do not post sensitive personal information in public issues.

## Scope

This Code of Conduct applies to project issues, pull requests, discussions, and other spaces where participants represent this project.
